# Parc Auto Manager

Aplicație web pentru firme care gestionează mașini și oferă servicii complete de întreținere pentru mai mulți proprietari.

## Specificații

Documentul de planificare se găsește în [`specs/index.html`](specs/index.html) și conține:

- **Module** — descrierea celor 7 module principale
- **Stack tehnologic** — HTML5, CSS3, JavaScript, PHP 8, MySQL 8
- **Baza de date** — schema cu 12 tabele relaționale
- **Structura fișierelor** — organizarea proiectului
- **Fluxuri** — scenarii de utilizare principale
- **Alerte** — 5 tipuri de notificări automate
- **Roluri** — Administrator, Utilizator, Vizitator
- **Mockup interactiv** — previzualizare desktop și mobil

## Module principale

| Modul | Descriere |
|---|---|
| Dashboard | Rezumat, alerte, grafice costuri |
| Mașini | Evidență flotă, documente, proprietari |
| Șoferi | Gestionare șoferi și permise |
| Service | Intervenții, piese, costuri |
| Asigurări | RCA / CASCO cu alerte expirare |
| Viniete | Roviniete România și internaționale |
| ITP | Evidență inspecții tehnice |

## Rulare spec

Deschide `specs/index.html` direct în browser — nu necesită server.

## Stack

`PHP 8` · `MySQL 8` · `HTML5` · `CSS3` · `JavaScript`
